## Things learned the hard way

### Byte-identical WASM across machines

`make wasm-fresh` compares the committed WASM with a fresh build. A fresh build only matches
when three things hold:

- **Fixed host triple.** Cargo hashes the `host:` line of `rustc -vV` into crate metadata.
  `wasmBuildOptions` (`web/scripts/wasm_build_flags.mjs`) points `RUSTC` at
  `web/scripts/rustc_fixed_host.sh`, which always reports `x86_64-unknown-linux-gnu`.
- **wasm-pack's own binaryen (version_117).** PATH copies of `wasm-opt` are hidden. Homebrew's
  131 optimizes differently.
- **The official prebuilt wasm-bindgen 0.2.126** (walrus 0.26.4) in `~/.cargo/bin`. On Apple
  silicon wasm-pack otherwise builds its own copy with walrus 0.26.5, and the bytes differ.

Toolchain: Rust 1.97.1, wasm-pack 0.14.0. CLAUDE.md's Gotchas section has the details.

### Dependency evidence

Measured full runs, before and after #122:

| Run | Time |
|---|---|
| Before #122, everything re-run | 28–32 min |
| After #122, everything re-run | 22 min |
| After #122, nothing changed (all five campaigns inherited) | about 23 min* |

\* This figure was measured on the `faster-evidence` branch before the last worker change.

What sets the speed:

- **Workers.** `web/scripts/campaign_workers.mjs` uses cores − 1 and 85% of `CAP_MEM` (else
  RAM). Campaigns running at the same time share that budget, weighted by each one's measured
  peak memory per worker (1–2.5 GiB). On this Mac a run uses 12/6/6 workers, then 12/9, then
  22 for the per-field campaign.
- **Overrides.** `CHRONICLE_CAMPAIGN_WORKERS`, `MIXED_MAX_PARALLEL` and
  `FIELD_MIXED_MAX_PARALLEL` set the count by hand.
- **What still runs single-threaded every time:** the covering array (about 6 min), the final
  config snapshot (about 6 min), and two WASM builds.

Footprint selection skips a campaign only when nothing it executed has changed. Any edit to
a harness file re-runs everything: `refresh_dependency_evidence.mjs`, a runner, or a campaign
test.

### Covering arrays are generated, and pinned in a test

`web/combinatorial/*` and `web/schema/generated/*` come from the schema. Never copy them
between repos; regenerate them:

- **Covering arrays:** steps 1–5 of `scripts/run_combinatorial_coverage.sh` with `pict`.
  PICT output is deterministic.
- **Ontology files:** `make -C web/schema -B all`.

Regenerating the arrays moves the refusal pins in
`web/src/lib/pipelineGraph/golden/configurationSpaceCampaign.test.ts`. Run it with
`CHRONICLE_PRINT_PINS=1` to print the new lists, then update them deliberately.

The SQL DDL and SHACL generators order some lines differently on the Linux box and on this
Mac. The content is the same, so don't commit a reorder-only diff.

`make -C web/schema methods-doc-check` is not part of `make check`. That is how
`docs/METHODS.md` drifted unnoticed until #122.

### "Artifact storage quota has been hit"

When gitleaks and OSV show red with this error, the scans themselves passed. What failed is
the **account-wide** 0.5 GB allowance for artifacts and Packages. It is metered in GB-hours
over the month and resets on the 1st.

- **Cause in October:** preview's canary failed on every run from 2026-08-25 to 10-03 and kept
  each Playwright report for 3 days. That held about 3.5 GB around the clock, and preview used
  1,400 GB-hours of a roughly 372 GB-hour monthly allowance.
- **Fix:** #123 and preview #65 cut report retention to 1 day. The Actions budget is now $1,
  which unblocked uploads at once.
- **How to diagnose:** run
  `gh api "/users/uzaira0/settings/billing/usage?year=Y&month=M"` (it needs
  `gh auth refresh -s user`). Look at the per-repo daily "Actions storage" figures. They
  show the cause even when the artifact list is empty.
- **No bypass:** admin merge does not work, because `enforce_admins` is on. Auto-merge is
  disabled on preview.

The old desktop-app build artifacts (Mac and Windows, about 950 MB) were deleted from
production on 2026-10-16. Nothing builds them anymore.

### The shipped-paths test under git hooks

A git hook exports `GIT_DIR`. Git then treats the current directory (`web/`) as the
repository root, so it never reads `.gitignore`. As a result `shippedLocalPaths.test.ts`
flagged a gitignored `__pycache__` file during `git push`. It now strips the `GIT_*`
variables before calling git (#122).
