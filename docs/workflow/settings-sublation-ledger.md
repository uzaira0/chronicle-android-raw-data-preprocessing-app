A source profile is sublated only when every applicable setting passes all six states:

1. **Preserved** — the source statement and locator survive unchanged.
2. **Typed** — role, target layer, ontology term, value shape, unit, comparator, and boundary
   convention are explicit where applicable.
3. **Bound** — the exact value compiles to a generated Chronicle contract slot or a named,
   versioned external executor; semantic similarity alone does not count.
4. **Exposed** — the GUI renders the setting in the profile's Acquisition, Event/Diary
   schema, Reconstruction, Quality, Derivation, Analysis, Validation, or Provenance section.
5. **Round-tripped** — GUI → preset → backend receipt → GUI preserves every setting identity
   and value without an ignored-key path.
6. **Conformant** — a source or source-derived fixture proves the selected executor reproduces
   the method. A preset with an unresolved, specification-only, or missing-signal setting is
   visibly non-runnable.

This is the acceptance test for the backend architecture and GUI. It permits a compact,
schema-driven interface, but it does not permit dropping a paper-specific choice merely
because no dedicated control existed before.

A blocked preset is a correct interim safety state, not final sublation. Final completion
requires every retained source-method variant and diary setup to be independently selectable
and reproducible through these six states; inspection-only objects, permanently inert controls,
and whole-source placeholders are incomplete.

## Verdict

Every enumerated setting maps. Nothing in the three columns required a new ontology
element beyond the expansions already adopted in the [sublation audit](sublation-audit.md)
and [device-state model](device-state-machine.md) — and two settings are direct
evidence FOR those expansions: `apply_threshold_to_fallback` needs the censoring contract,
and `use_background_apps_file` needs stage-scoped policy rules. Residue is unchanged:
presentation internals of the prior tools only. EYES/P&T preset EXACTNESS remains gated on
fixture conformance (see the [sublation audit](sublation-audit.md)) — the mapping above is
the semantic account, not the parity
proof.
