# Product-owned crates that carry semantic/computational authority.
# The adapter's cfg(wasm)-only facade is target-incompatible with native
# cargo-mutants; its delegate is unit-tested and its export is browser-tested.
# Multiple exact inline exclusion expressions are comma-separated, and the
# entry's own fields are '|'-separated, so an inline expression can contain
# neither character: a regex carrying one is split in half and cargo-mutants
# rejects the unclosed group. The runtime and matcher entries each shipped
# such a regex and their mutation gate could not start; both are now written
# as separate expressions, which match exactly the same mutants.
# The kernel's contract-export binary is exercised by the contract drift gate;
# cargo test cannot call its `main` in a mutant sandbox. The matcher's optional
# Python-only facade is outside the browser product and creates the bulk of the
# crate's 704,021 mutants as combinatorial tuple-return replacements — 702,769
# for `match_app_usage_update_arrays` alone. `PyResult<` and `PyErr` name that
# facade by its return types, which appear nowhere above the crate's
# `#[cfg(feature = "python")]` block at src/lib.rs:1246, and remove 703,741 of
# the 704,021. They are written without the `->`: an exclusion expression may
# not begin with `-`, which cargo-mutants' argument parser reads as a flag.
#
# The entry also carried ` in to_py_error`, ` in match_app_usage`,
# ` in split_overlapping_sessions_py` and ` in _rust_app_usage_matcher`. That
# shape only matches operator mutants *inside* a function body — a
# function-replacement mutant is named `replace <fn> -> <type> with <value>`
# and carries no ` in ` — so ` in to_py_error` and ` in _rust_app_usage_matcher`
# matched nothing at all, and ` in match_app_usage` matched 34 mutants of which
# not one was in the PyO3 `match_app_usage`: all 34 were in
# match_app_usage_core, match_app_usage_update_indices_core and
# match_app_usage_update_indices_with_proximity_core, the binding-agnostic core
# this repo names as the single source of truth for session matching, and 24 of
# them are caught. Excluding them cut the entry from 279 mutants to 245 and
# deleted 24 real kills from its score. Those three fragments are gone;
# ` in split_overlapping_sessions_py$` stays because it matches exactly one real
# facade mutant, the `==` at src/lib.rs:1433:35 inside the wrapper body.
# The core has 44 survivors — comparison boundaries in
# split_overlapping_sessions, both proximity matchers, the update-indices core
# and SparseOpenStarts. They are recorded in docs/validation/KERNEL_MUTATION.md
# and are a campaign of their own; this entry is left honest and red rather
# than blanket-excluded.
#
# check-rust-quality.sh enforces both halves of that before every campaign: an
# expression matching zero mutants fails the gate by name, and the excluded
# mutants are themselves run so an expression covering a caught mutant fails
# instead of quietly inflating the score.
# Optional fields after the exclusion regex ratchet line, region, and function
# coverage for an established authority below the shared new-code defaults.
# The final field lists product features required by both coverage and mutation;
# omitting `incremental-v2` would silently test the retired non-authoritative
# kernel build instead of the production 55-step query engine.
# A seventh `no-default-features` field keeps a gate on the exact feature set
# linked into the browser when a crate's defaults only expose another product.
# An eighth field scopes coverage measurement only: it becomes llvm-cov's
# `--ignore-filename-regex`. It is for a source file that is entirely test
# scaffolding, never for production code that is merely under-covered — the
# ratchet fields above are the honest place to record that. llvm-cov takes one
# expression, and this field cannot hold a '|' or a ',', so it names one file.
# The gate resolves it against the crate's real sources and refuses to run if
# it matches nothing, because a scope that has drifted off its anchor silently
# measures the whole crate while reading as a deliberate exemption.
#

# for the inline field, so they name a file instead:

# expression per line, grouped under the reason each class is equivalent. Such
# a file is also the only place an expression may contain a ',' or a '|'.
