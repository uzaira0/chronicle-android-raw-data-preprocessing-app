## Goal

Finish all 143 papers in `android-143-corpus.json`: preserve every disclosed,
in-scope Android data-processing concept and variation in Chronicle's canonical
ontology and application, fix every demonstrated representation gap, and deliver
the evidence for a research-paper claim covering this exact corpus.

Corpus membership is fixed. Source corrections, supplements and code belonging
to these same papers may clarify their methods; they do not add papers. New

## Completion criteria

Completion requires all five results:

1. **143/143 paper coverage rows finalized.** Each row identifies the inspected
   source versions, exact method/source locators, ontology mappings, operation
   and variant composition, populated-record support, proof references, and any
   source limitations. Reuse the existing source audits and working evidence;
   this is a consolidation of completed work, not 143 reviews restarted.
2. **Zero known disclosed-but-unsupported concepts.** Every applicable event or
   observation type, schema, operation, parameter, temporal/session rule,
   missingness/quality rule, aggregation/feature, configuration variation,
   ordering/dependency, output and provenance constraint is accounted for.
   Contradictory or different meanings stay distinct. A field name or an opaque
   JSON copy alone does not prove that its meaning or relationships are modeled.
3. **Required application behavior works.** Demonstrated gaps are repaired in
   the existing schema/import/settings/UI/persistence owners with the smallest
   necessary changes. Supplied records and configurations survive actual import,
   save, reload and the existing export path where applicable. Shared proofs are
   reused when their semantic coverage is explicit. Positive examples and
   relevant invalid ownership, missing/null/empty and composition cases pass.
4. **Source limits are explicit and honest.** A paper can be finalized with a
   precisely stated limitation on inaccessible or unreported details, provided
   every inspected disclosed concept is covered and no implementation gap is
   mislabeled as missing source information. These limited rows remain visibly
   distinct in the final tally and manuscript. No thresholds, joins, clocks,
   schemas or deployed settings are invented.
5. **One coherent final delivery.** The 143-row coverage matrix, canonical
   ontology, generated artifacts, app behavior, regression/composition checks and
   source-limited manuscript claim agree at the same final working revision.
   Independent source-to-term review resolves substantive mapping disagreements.
   Existing separate scientific hypothesis/novelty gates remain separately
   assessed; whole-study result reproduction is not required for this goal.

The finish line is **143 finalized rows, zero unexplained disclosed semantic
gaps, passing application proofs, and the bounded manuscript claim delivered**.
Finalized rows with source limitations count toward 143 but are always reported
separately. No paper can be silently dropped from the denominator.
