## Notes

- **Production identity.** The brief says the live app is "a deliberate rollback deploy". GitHub's deployments API (`repos/uzaira0/chronicle-android-raw-data-preprocessing-app/deployments`) says the newest `github-pages` deployment is `e16d4abb` from `main` at 2026-08-05T08:23:55Z ("fix: track runtime WASM deploy artifact (#97)"). That deploy came after the 2026-07-29 `rollback/2026-06-27-build` deployment. The live `index.html` has `last-modified: Wed, 05 Aug 2026 08:24:10 GMT`, which matches. The `rollback/*` branch no longer exists on `public`.
- **Lighthouse caveat.** The local server on :4318 sends `Cache-Control: no-cache` and does not compress WASM. The packs and runtime WASM are already compressed, though (gzip saves <3 %), so the blocking-registry waterfall would look the same in production for this branch.
- **The 51 failing chromium tests** (base-full-chromium.clean.log) are cited, not fixed. Most of them (`rosenthal-*`, `research-method-profile-import`, `device-use-sessions`, …) fail on the "Load supported preprocessing settings" button's disabled state. The ones that bear on readiness are `app.spec.ts:1512` (saved project not loadable after reload) and `durability-fault-injection.spec.ts:244` (alternating-slot recovery export).
